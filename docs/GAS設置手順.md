# GAS（Google Apps Script）設置手順

スプレッドシート側のプログラムを設置する手順です。画面操作だけで完了します（所要 約10分）。

## 1. スプレッドシートを作る

1. ブラウザで https://sheets.new を開く（Googleアカウントでログインした状態で）
2. 左上の「無題のスプレッドシート」をクリックし、名前を「IBS記録」などに変更

## 2. プログラム編集画面を開く

1. メニューの **拡張機能 → Apps Script** をクリック
2. 新しいタブでプログラム編集画面が開く
3. 左上の「無題のプロジェクト」をクリックし、「IBSログ」などに変更

## 3. コードを貼り付ける

1. 画面中央に `function myFunction() {...}` という数行のコードが最初から入っているので、**全部選択して削除**
2. このリポジトリの `gas/コード.gs` の中身を**全部コピーして貼り付け**
3. 上部の **💾（保存）アイコン**（またはCmd+S）で保存

## 4. 初期セットアップを実行する（シートの自動作成）

1. 上部のツールバーにある関数の選択欄（「myFunction」等と表示されているプルダウン）で **initialSetup** を選ぶ
2. **▷ 実行** をクリック
3. 初回は「承認が必要です」と出るので:
   - 「権限を確認」→ 自分のGoogleアカウントを選択
   - 「このアプリはGoogleで確認されていません」と出たら **「詳細」→「（プロジェクト名）に移動」** をクリック
   - 「許可」をクリック
   ※ これは「自分が作ったプログラムに、自分のシートの読み書きを許可する」操作です
4. スプレッドシートのタブに戻り、「イベントログ」「デイリーログ」「設定」の3シートができていれば成功

## 5. ウェブアプリとして公開する（アプリとの接続口を作る）

1. Apps Script画面右上の **「デプロイ」→「新しいデプロイ」** をクリック
2. 左の歯車アイコン ⚙ →「**ウェブアプリ**」を選ぶ
3. 次のように設定:
   - 説明: 空欄でOK
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   ※「全員」にするのはアプリ（PWA）がログインなしで送信するためです。URLを知らない人はアクセスできません
4. 「デプロイ」をクリック（ここでも承認画面が出たら手順4と同様に許可）
5. **「ウェブアプリ」のURL**（`https://script.google.com/macros/s/～/exec`）が表示されるので **コピー**

## 6. URLをアプリに設定する

コピーしたURLをClaude Codeに伝えてください。`config.js` への反映とテスト送信を行います。

## 7. 合言葉を設定する（推奨）

「設定」シートの「合言葉」の行（K列に「合言葉」とある行）のL列に、好きな合言葉を入力してください。
以後、その合言葉を知らない相手はデータの閲覧も書き込みもできなくなります。
アプリを開くと合言葉の入力画面が出るので、同じものを1回入力すれば完了です（端末に保存されます）。

---

## 【重要】コードを更新したときの再デプロイ

`gas/コード.gs` を修正して貼り直した場合、保存しただけでは公開中のウェブアプリに反映されません。

1. **「デプロイ」→「デプロイを管理」**
2. 鉛筆アイコン ✏ → バージョンを「**新バージョン**」に変更
3. 「デプロイ」をクリック

※ この方法ならURLは変わらないので、config.js の修正は不要です。
