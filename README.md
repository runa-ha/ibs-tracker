# IBSログ - 体調管理システム

IBS（過敏性腸症候群）の症状・服薬・生活習慣を記録し、自動で分析するシステムです。

## 全体構成

```
[スマホのアプリ画面（PWA）]          [Google スプレッドシート]
  GitHub Pages でホスティング              記録と分析の本体
┌──────────────────┐    送信    ┌─────────────────────┐
│ 記録タブ: 排便・服薬  │ ───────▶ │ イベントログ（1行1记录） │
│ 今日タブ: 生活記録    │  (doPost) │ デイリーログ（1日1行）   │
│ 上部: 簡易集計カード  │ ◀─────── │ 設定（薬・タグ・閾値）    │
└──────────────────┘   取得     └─────────────────────┘
                        (doGet)            │ 毎朝5時 自動実行
                                          ▼ buildDashboard()
                               ┌─────────────────────┐
                               │ 日別ステート / 週次サマリー │
                               │ トリガー分析 / カレンダー    │
                               │ サイクルビュー / メンタル×体調│
                               │ 排便リズム                │
                               └─────────────────────┘
```

- **PWA（このリポジトリ）**: 素のHTML/CSS/JSのみ。スマホのホーム画面に追加してアプリとして使う
- **GAS（`gas/コード.gs`）**: スプレッドシート付属のプログラム。記録の受信と分析を担当
- 健康データ本体はスプレッドシートにのみ保存され、このリポジトリには含まれません

## ファイル一覧

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（2タブ＋集計カード） |
| `style.css` | 見た目。色は先頭の `:root` でまとめて変更可 |
| `app.js` | 動作の本体。送信キュー・ボタン生成など |
| `config.js` | **GASのURLをここに書く**（これだけ書き換えれば接続完了） |
| `manifest.json` | ホーム画面追加用の設定 |
| `service-worker.js` | オフラインでも画面を開けるようにする仕組み |
| `gas/コード.gs` | スプレッドシート側に貼り付けるコード |
| `docs/GAS設置手順.md` | GASの設置手順（画面操作レベル） |

## セットアップ手順（概要）

1. GitHub Pages でこのリポジトリを公開（済みならスキップ）
2. `docs/GAS設置手順.md` に従い、スプレッドシートにGASを設置してURLを取得
3. `config.js` の `GAS_URL` を取得したURLに書き換えてプッシュ
4. スマホでサイトを開き「ホーム画面に追加」

## よくある改修の手順

### 薬・食事タグを追加/変更/並べ替えしたい
スプレッドシートの「設定」シートを編集するだけです。**コード修正・再デプロイは不要。**
- 薬: A〜C列に「薬名・表示順・有効」を追記。使わなくなった薬は「有効」を「無効」にする（行削除しない方が過去の記録と整合します）
- タグ: G〜I列に同様に追記
- アプリを開き直すと反映されます

### 便秘の警戒ラインや下痢判定の閾値を変えたい
「設定」シートのK〜L列の値を変えるだけです（便秘警戒日数 / 下痢判定ブリストル / 下痢判定回数）。

### グラフや分析を追加したい
`gas/コード.gs` の `buildDashboard()` に関数を1つ足す形で追加します。
既存の `buildRhythm_()` などを参考にしてください。分析の土台データは
`computeDailyStates_()` が返す「日別ステート」（1日1レコード）です。

### 生理周期など新しいデータを組み込みたい
1. スプレッドシートに「周期ログ」シートを追加（列: 周期開始日）
2. `readDaily_()` と同様の読み込み関数を作り、日付キーで結合する
分析はすべて日付キーで結合しているので、シートを1枚足すだけで拡張できます。

### 通院リマインダー・薬の在庫アラート
「設定」シートに次回通院日（K列に既に項目あり）や薬の残数（D列）を入れ、
日次トリガーで動く関数にメール送信（`MailApp.sendEmail`）を1つ足せば実装できます。

### 画面のファイルを変更したとき
このリポジトリにプッシュすれば1〜2分でGitHub Pagesに反映されます。
アプリの見た目が更新されない場合はアプリを一度閉じて開き直してください。
大きな変更をしたときは `service-worker.js` の `CACHE_NAME` の数字を上げてください。

### さらに大きな改修をしたいとき
このフォルダを Claude Code で開いて「◯◯したい」と依頼すれば差分改修できます。

## 注意（プライバシーとセキュリティ）

- このリポジトリは公開ですが、**健康データは一切含まれません**（データはあなたのスプレッドシートのみに保存）
- **合言葉による保護**: 「設定」シートの「合言葉」に値を書くと、以後は合言葉つきの通信しか受け付けません（閲覧・書き込みとも）。合言葉はスプレッドシート（非公開）とスマホの中にだけ存在し、このリポジトリには含まれません
- 合言葉を変更したら、アプリ側でも新しい合言葉の入力を求められます
- スマホを買い替えたときは、新しい端末で初回に合言葉を入力すれば引き続き使えます
